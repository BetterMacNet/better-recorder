# Security

Better Recorder Pro's public repository contains product information only. The application source code is not public.

## Reporting a security concern

Please do not publish security vulnerabilities, recordings, screenshots with private content, credentials, or other sensitive information in a public issue.

Email [support@bettermac.net](mailto:support@bettermac.net) with `Security report` in the subject. You can also use the [Support Center](https://bettermac.net/en/support/?product=better-recorder) or [Contact Us](https://bettermac.net/en/contact/?product=better-recorder). Ask support for a private channel before sending sensitive details; the public contact pages do not provide a dedicated security mailbox or encryption instructions.

There is no public security-response SLA in this repository. The support team can confirm the current handling and support status for your release.

## Supported release information

The repository currently describes Better Recorder Pro 1.2.0. Updates are delivered through the [Mac App Store](https://apps.apple.com/app/id6809041086); contact support to confirm whether a particular release is still supported.

## Privacy when reporting

Before sharing logs or screenshots, remove credentials, personal information, private file paths, LAN Share links and PINs, network addresses, and any recorded content that could identify you or other people.
